v1.0.1 October 20, 2026 Latest

Fixed

  • Zipper noise on manual fader movement — all output-stage gains now use per-sample one-pole smoothing (10 ms). Dragging a fader with the mouse no longer produces a staircase amplitude modulation.
  • Zipper noise on host automation — SAMPLE_ACCURATE_AUTOMATION disabled. Full host buffers are processed, so parameter values stay constant within a block and no step can occur.
  • FFDN delay buffer — now scales with sample rate (500 ms × sample_rate) instead of being hard-coded to 24000 samples.
  • FFDN feedback computed from clamped delay — prevents premature tail truncation when Size exceeds buffer capacity.
  • Velvet-Noise filter is now sample-rate aware — pulse count, LP coefficient, and RRS width all scale correctly at 44.1 / 48 / 88.2 / 96 kHz.
  • FFDN drive stability — velvet_saturate no longer applies a makeup gain. Restores unity small-signal gain and eliminates the FDN instability at high drive amounts.
  • FFDN Dynamics audibility — Attack now uses a square-root curve and blend-based attenuation. Ducking uses a dB-mapped exponential (up to −24 dB). Gate threshold widened to [−60, −10] dBFS with a squared fade.
  • Undo/redo no longer cuts the reverb tail — snapshots do not reset the DSP state, so undoing a parameter edit produces a smooth 10 ms ramp instead of an audible cut.
  • Canonical factory presets — apply_factory_preset resets texture extras, Velvet, FFDN card masters, and EQ master before applying. Every factory preset produces a complete, reproducible state.
  • Partial XML presets — CloudSeed — ParsedPreset.cloudseed is now [Option<f32>; 49]. Files with only FFDN, only Illusion, or a subset of CloudSeed load non-destructively.
  • Partial XML presets — Texture Rack — ParsedPreset.texture and .enabled are now [Option<f32>; 32] and [Option<bool>; 6]. XML without a <TextureRack> block no longer resets texture parameters.
  • Clippy-clean workspace — all 26 production lints and 23 UI/test lints resolved. cargo clippy --workspace --all-targets -- -D warnings completes with zero warnings.
  • Redundant permutation loop removed in velvet_matrix.rs. Output was already bit-identical.
  • CI race condition — the three per-platform workflows were unified into a single release.yml. Builds upload artifacts, and exactly one release is created after all platforms succeed.

Changed

  • User preset directory scan is throttled to 0.5 s (was per-frame).
  • current_preset is persisted across sessions via #[persist].
  • About modal now shows the official website link.
  • Repository cleanup — repomix AI-context files removed from version control.

Notes

  • All 33 DSP tests pass. The suite covers every *_is_bit_identical and every *_keeps_network_stable check, so the audio path is verified to be unchanged.
  • Factory presets with attack > 0 may sound stronger because the Dynamics stages are now much more audible at the same parameter values.

System Requirements

PEJVAK RVB runs on any modern 64-bit system.

⚙️

Minimum

  • OS Windows 10 · macOS 10.15 · Linux (glibc 2.31+)
  • CPU x86_64 (SSE2) or Apple Silicon
  • RAM 4 GB
  • Disk 50 MB free space
  • Format VST3 or CLAP host (64-bit)
✨

Recommended

  • OS Windows 11 · macOS 12+ · Modern Linux
  • CPU Apple Silicon or x86_64 with AVX2
  • RAM 8 GB or more
  • Disk 100 MB free (presets + manual cache)
  • Format VST3 (64-bit) or CLAP

Note: Both VST3 and CLAP formats ship as native universal binaries on macOS (Intel + Apple Silicon). AVX2 is used automatically when available for the SIMD fast path, but is never required.
